How to use Perses

Four quick steps, then the full list of tags.

Open Perses

Click "Start chatting free". You can try it as a guest, no sign-up needed.

Pick a mode

Choose General, Study Focus, Code Helper, Math Solver, Artist, Writer or Exam Prep in the sidebar.

Type or talk

Type a message, tap the mic, or press the + button to add photos and documents.

Use tags

Start a message with / for shortcuts like /image, /code and /math.

Slash tags

Type / at the start of your message. Click an example to copy it.

TagWhat it doesExample
/imageCreates a picture from your description/image a cozy mountain cabin at sunrise
/promptWrites a ready-to-use prompt for any AI task/prompt write a friendly cold email to a client
/codeWrites or fixes code with an explanation/code a Python function that reverses a list
/writePolished writing: emails, essays, speeches/write a short farewell speech for my teacher
/mathSolves step by step, with formulas/math solve 2x^2 - 5x + 2 = 0
/summarizeSummarizes pasted text or an attached document/summarize (after attaching a file)

More: say remember that I prefer short answers and Perses saves it to your memory. Select any text in an answer to rewrite, shorten, translate or explain it.
